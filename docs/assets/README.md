# 発表資料用 デモ画像・GIF配置フォルダ

ここに以下のファイル名でスクリーンショットやGIFを置くと、`presentation/index.html` を開いた際に自動でデモ枠に読み込まれます。
（ファイルが無い場合でも、HTML内蔵のターミナル・レポートプレビューが自動で表示されるため、そのままでも説明が完結します）

- `demo_execution.gif` : スライド4（デモ①：VulNavi エージェント実行画面のGIFまたは画像）
- `demo_report.png` : スライド5（デモ②：生成された脆弱性対応まとめレポートのスクショまたはGIF）

また、ブラウザ上でスライド4・スライド5の下部にある **「📷 デモ画像 / GIF を差し替える」** 枠をクリックして、その場で任意の画像ファイルを選択・表示することも可能です。
