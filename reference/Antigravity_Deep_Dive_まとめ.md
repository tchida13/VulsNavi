## 1. 前半：「ソフトウェアファクトリー」（前日の基調講演の再演）

### 背景

- 2025年12月がソフトウェア開発の転換点。以降、Gemini 3 Flash → 3.1 Pro → 3.8 Flash → Gemini 4（Argon / Carbon）とモデル更新が続いている。
- Antigravity はモデルチーム・研究チームと協力してハーネスを最適化している。同じ Gemini モデルでも、Antigravity 上で動かした方がベンチマーク結果が良い。
- Google I/O でアプリを4つに分割：メインアプリ、CLI、IDE 拡張機能、Python SDK。

### コンセプト

- 日立（1969年、横浜）や東芝（1977年）の「ソフトウェア工場」、トヨタの自働化（Jidoka）を例に、職人作業から、繰り返せて品質ゲートを持つ「並列の組立ライン」へ移ろうという話。
- 単一のチャットスレッドでは、人間が入力・レビューのボトルネックになる。

### 主な機能

- **/boost**：サブエージェントを直列に連携させ、結果を検証してから返す。
- **/teamwork-preview**：専門ペルソナのチームが互いに提案・批評・改善し合う。50体以上を数時間〜数日、無人で実行できる。社内では夜間実行に使われている。OS をゼロから構築して Doom を動かした事例や、Fortran・COBOL・古い C++ を Rust に移行した事例がある。
- **リモートコントロール**：任意のブラウザから接続できる。スマホやスマートウォッチに通知が届き、承認や軌道修正が必要なときだけ介入すればよい。
- **自動化**：cron によるスケジュール実行、`.agents/hooks.json` の宣言的フック、Webhook のように使えるバックグラウンドのサイドカー。
- **`.gemini/brain`**：会話の JSON 軌跡、ウォークスルー、分離された Git ワークツリーを自動保存する。中断・再開やモデルの切り替えができる。

### 社内実績

Alphabet 社内で月間10万人以上が Gemini 4 Argon を利用。エージェントが書くコードは35%増え、提出後のロールバックは30%減った。

### ソフトウェアファクトリー構築の5ステップ

1. ワーカー（カスタムサブエージェント）を `.agents/agents` に Markdown で定義する。MCP・ツール・権限・モデルをエージェントごとに指定できる。
2. ライン（スキル）を `.agents/skills` に、標準作業手順として定義する。
3. 読み取り専用の監査エージェント（自働化型インスペクター）を追加する。セキュリティ、アクセシビリティ、ポリシーをチェックする。
4. これらをプラグインにまとめ、チームでバージョン管理する。
5. GitHub issue、cron、Webhook、NAS の監視フォルダなどをトリガーに自動起動する。最後に検証済みの PR とウォークスルーが出力される。

始め方としては、リスクが低く繰り返せるタスクがおすすめ（例：古いポリフィルや API の削除）。

## 2. 質疑応答（前半）

- **サブエージェントとスキルの違い**：形式はスキルと同じ Markdown だが、MCP・スキル・権限の範囲を限定・除外できる。メインエージェントとサブエージェントの2種類がある。コードで定義する方法も追加予定。
- **Teamwork のチーム構成**：6つのモードで動き、タスクに応じて動的に構成される（20〜150体）。詳細は antigravity.google/blog。
- **IDE とアプリ**：IDE（VS Code フォーク）から、ゼロから作ったアプリと拡張機能へ移行中。
- **サブエージェントのテスト**：評価セットで検証する。フックで、ファイル書き込み後にテストを自動実行できる。
- **他社との違い**：Google は研究・モデル・推論基盤・製品まで全体を持っている。同じハーネスが NotebookLM や AI Studio でも使われている。

## 3. Deep Dive 本編

### 4つの柱

1. エージェントエンジン：設定・会話・認証情報を全サーフェスで共有する。
2. 成果物（Artifact）による検証：PDF、PPTX、XLSX、DOCX、HTML、アプリに対応。動画を含むほぼすべてのファイルをアップロードできる。
3. 組み合わせ可能なカスタマイズ部品（プラグインマーケットプレイス）。
4. 多層防御：OS カーネルのサンドボックスと Gemini Enterprise のガバナンス。

### モデル

- **Gemini 4 Argon / Carbon**：入力・出力とも100万トークン。effort を選べる（デフォルトは medium、Boost や Teamwork では low 推奨）。
- **Gemini 3.8 Flash**：実行やレビュー、bash の実行に向く。「オーケストレーションは Pro、実行は Flash」が推奨構成。
- **NanoBanana2**：画像生成用。
- **Claude Sonnet 5.5 / Opus 5.5**：複数モデル間で作業を引き継いだりレビューし合ったりできる。

### 事例（antigravity.google/use-cases）

- YouTube：CPU 使用率を50%削減。
- Wing：シミュレーターの欠陥を18件発見。
- バグキューの72%を3時間以内に解消したチーム。
- Fortran→Rust 移行で1.8倍の高速化。

### コンテキスト管理とプラン

- `/compact` で圧縮、`/context` で使用状況を確認できる。スキルやルールは薄くする傾向にある。
- 全プランに 3.8 Flash が含まれ、拡張機能ではタブ補完が無制限。Pro / Ultra で Argon や Claude が使える。5時間ごとのリセットと週次上限がある。
- 会場からは「中小企業には価格がエンタープライズ寄り」という意見が出た。

### デモ

- **/grill-me**：実装前に AI が質問を重ねてゴールをすり合わせる。複数選択式の質問や音声入力に対応している。
- **/btw**：実行中に別の質問を並行して投げられる。
- **権限の auto モード**：既定はサンドボックス実行。`/plan` を使うと、設定に関係なく最後にレビューで止まる。

### サーフェス

- 社内では Googler の約90%が Web 版を使っている。講演者は作業の約80%をリモートコントロール経由で行っている。
- **アプリ**：マルチエージェントの監督、並列会話と分割表示、会話レール、PDF へのコメント。
- **CLI**：ヘッドレス実行（`agy -p`）、Shift+Tab でモード切替、サンドボックス、JSON スキーマ対応。最新機能は CLI に先に入る。
- **IDE 拡張**：Xcode、Zed、Android Studio（本日から）、VS Code、Visual Studio、JetBrains、Eclipse。ACP（Agent Client Protocol）を採用している。
- **リモートコントロール**：CLI 版とアプリ版があり、併用できる。

### Python SDK

- オープンソース（GitHub）。モデルの呼び出しを差し替えられる。Gemma 27B を LiteRT で完全オフライン・無料で実行した例がある。OpenAI 互換のエンドポイントにも対応。
- ハイブリッドワークフロー：機密データの処理だけを端末内で行うなど、コンプライアンスに合わせた構成ができる。
- 宣言的にコンテキストとスコープを制御できる。CI/CD への組み込みにも推奨。

### サンドボックスと権限

- Windows は WSL、macOS はコンテナ方式。外向きの通信はデフォルトで無効（許可リスト方式）。
- ツールごとに細かい権限設定ができる。CLI には Vim モードもある。

### エンジニアリングループ

- `/plan`、`/grill-me`、`/generative-ui` を使う。組み込みコマンドは、呼び出すまでコンテキストを消費しない。
- ブラウザサブエージェント（Chrome MCP）と内蔵ブラウザで、生成結果を動画や画像で確認できる。
- `/artifact` で成果物を確認できる。作業完了ごとにウォークスルーが作成される。
- UI 共有：データをダッシュボード化できる（オフラインで動く）。Apps Script との連携例もある。
- Google Labs の Stitch と連携してデザインを生成できる。
- Git とターミナルがネイティブに組み込まれている。

### 並列エージェントとループ

- 会話ごとに分離した Git ワークツリーを使う（`.gemini` 内で管理）。サブエージェント間の高度な連携機能を開発中。
- `/learn`：うまくいった会話から、スキルやルールを更新する。
- スケジュール・自動化の例：講演者は、メールやカレンダーから止まっている案件やフォローアップが必要な相手を洗い出させている。

## 5. カスタマイズとマーケットプレイス

- マーケットプレイスは2日前に公開された。Google 以外のプラグインも拡充中。
- **UI サイドカー**：プラグインがサイドパネルを制御できる。
- **設定の保存先**：グローバル単位とプロジェクト単位。
- **ルール**（`.agents/rules`）：発動条件は「常時」「glob」「モデル判断」から選ぶ。上限は 24K。
- **スキル**：手動で呼び出すほか、モデルが判断して参照する。
- **ライフサイクルフック**：例として、ファイル書き込み時に lint を実行する。
- **MCP**：ローカル、リモート、HTTP、ソケットに対応。ステートレス仕様にも追従。
- **連携パートナー**：Canva、CrowdStrike、Figma、Databricks、Datadog、Dropbox、Unity など。Build with Google for Science も紹介された。
- **Installed タブ**：プラグイン、スキル、MCP を一覧で確認できる。
- **プラグイン作成**：最小構成は `plugin.json` のみ。CLI に仕様チェック用のバリデーターがある。
- **ワークフロー**：旧ワークフローをスキルに移行するコマンドがある。新ワークフロー機能も近日公開予定。
- **Q&A**：「高性能モデルならルールは不要か」→ 当面は小型モデルとの併用のため必要。
- **リモート型プロジェクト**（段階的に提供開始）：GitHub と Google Drive を1プロジェクトにまとめ、各デバイスと同期する。

## 6. Teamwork と大規模オーケストレーション

- 長時間タスクでは、サブエージェントに分割してコンパクション（文脈の圧縮）を回避すると性能が上がる。
- 承認待ちのサブエージェントへは Alt+J で移動、Ctrl+K で承認できる。
- **事例**
  - グラフ処理：32台の VM で60〜90倍にスケールし、DRAM 使用量は約100分の1。
  - TPU カーネル最適化：メモリ使用量を185分の1にし、8〜15倍高速化。
  - 数学の予想7件を解決し、RISC-V シミュレーターを構築。
- **Gemini Enterprise**：Standard と Plus がある。Workforce Identity Federation、GCP の ADC、複数リージョンに対応。

## 7. 最終 Q&A

- **推論レベルの使い分け**：単発の計画・評価、画像や動画の分析、デバッグには high。サブエージェントやオーケストレーションには low か Flash。
- **Argon と Carbon の違い**：Carbon はサイバーセキュリティと長時間タスクに特に強い。
- **ログ分析**：Gemini Enterprise に管理画面と利用状況ダッシュボードがある。
- **プロンプトの自動改善**：現時点では機能なし（講演者は /btw で代用している）。
- **キー操作**：macOS は Option、Windows は Alt。
- **サブエージェントの手動呼び出し**：スキルのように呼び出せる。メインエージェントに指定することも可能。
- **マーケットプレイス**：キュレーション型で、セキュリティとコンプライアンスを審査している。

## 8. セットアップ手順（ハッカソン用クレジット）

1. Google Cloud Console で、クレジットを適用したプロジェクトの ID を確認する。
2. antigravity.google からダウンロードする（macOS / Windows / Linux。CLI はワンコマンドでインストール可能）。
3. **CLI の場合**：`/logout` → 「Google Cloud project」→「Continue with Google Cloud」→ ブラウザでログイン → コードを貼り付け → プロジェクト ID とリージョンを入力 → 規約に同意。
4. **アプリの場合**：「Sign Out」→「Use business account」→「Continue with Google Cloud」→「Pay As You Go」→ プロジェクト ID を入力 → リージョンは Global → 規約に同意。

## 9. アイデアソン（ワークショップ、ランチ前まで）

- **3つの約束**：経験は問わない、困ったら挙手する（赤：Google スタッフ、緑と青：メンター）、仲良くやる。
- **自己紹介**：テーブルごとに3〜4人で3分間。
- **アイデアシート**
  1. ステップ2-1：身近で具体的な困りごとを書く（3分）。例：実家の母がスマホの謎の画面について毎回電話で聞いてくる。
  2. 右半分：困りごとを代わりに解決してくれる人物像を、できるだけ多く書き出す（3分）。コツは「何を見て何をしてくれるか」を具体的に書くこと。
  3. 旗印シート（5分）：困りごと、エージェント名（例：母のスマホ通訳エージェント）、入力、作業手順、アウトプットを書く。
- **30秒ピッチの例**
  - 家電の組み立て失敗を防ぐアプリ
  - スニーカーの店頭抽選と整理券をアプリ化
  - 地方の高齢者のお祭り運営を支援（キッチンカーの手配、企画、会計）
  - 消耗品の消費予測と、スーパーでの買い忘れリマインド
  - Box や Notion に散らばったコミュニティの情報を AI で探すアプリ
- **チームビルディング**（12:35〜12:40）：1チーム最大4名（2〜3人推奨）。ソロも可。メンターは各チームに分散する。
- 12:40からランチ。クーポンのメールが届いていない人は、迷惑メールフォルダを確認するよう案内があった。
